Papernote

Desktop redesign specification · printable one-pager

Layout

  • No top chrome. Native traffic lights only; they fade out in Zen.
  • One centered text column, 520–1200 px via the bottom-bar slider.
  • Default width 860 px. Paper background #FBFBF9.
  • One 44 px bottom bar, flush to the window edge, translucent and blurred. It holds every control.

Modes

Live (default): markdown is rendered and stays directly editable. Typing # , - , > , **bold**, *italic*, ~~strike~~, or [link](url) formats in place.

Markdown: raw source in a plain textarea. Toggle with the segmented control or ⌘E. Each mode keeps its own font.

Zen

  • ⌘. toggles. Esc also exits.
  • Hides the bottom bar and traffic lights; forces Live mode.
  • Transient pill toast confirms: “Zen — ⌘. to come back”.

Bottom bar · left to right

Live / Markdown · Heading · List · Quote · B · I · S · Link · Search · File It · Publish · Copy · width slider · font name · word count · ◐

In Live, format buttons apply rich formatting. In Markdown they insert syntax.

Shortcuts

⌘. Zen · ⌘E mode · ⌘O search · ⌘B/⌘I bold/italic · ⌘K link · ⌘1–4 file · Esc close/exit

On Windows, use Ctrl in place of ⌘.

File It · Search · Publish · Copy

File It areas: Thoughts, Notes, Archive (⌘1–3). Add more areas from the popover.

Search is an overlay of recent notes. Publish writes a local read-only HTML page. Copy offers Markdown or formatted rich text.

Fonts · 12, no serifs

Mono: Fira Mono, Space Mono, Inconsolata, Red Hat Mono, Spline Sans Mono, Overpass Mono, Sometype Mono.

Sans: Figtree, Manrope, Hanken Grotesk, Instrument Sans, Rubik.

Defaults: Rubik (Live) · Overpass Mono (Markdown). The font menu previews each face with “A quiet tool for loud thoughts.”
